# Sir Schedule's Bot

#### 

## Overview



Do you have to do something every morning for your discord server? Any message you want to give someone? Or do you just want to send a check in message? In any case, this discord bot is designed so you can automate daily tasks!



Preload a question of the day to send at a specific time, schedule a DM to a friend, or get a surprise with our AI integration features!



Currently in development, but is now available!



**Please welcome v0.2.2! This version allows for a more updated \& dynamic scheduling system. More features and QOL updates to come in the near future.**
